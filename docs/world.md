# 全臺立體地景（2026-11-28）

使用者需求：像どこでもロケハン那樣，先把臺灣的基本立體地景全部搭好，鏡頭移到哪裡就看到哪裡；之後各景點的歷史年代與故事疊在這層上面。

網址：`./?place=tw`（預設臺南車站）、`./?place=tw&id=<地景資料庫 id>`、`./?place=tw&ll=緯度,經度&d=距離&hd=方位&pt=俯角`。
入口：景點列的「全臺立體」（目前景點有座標就飛到那裡）、首頁導覽卡、全臺地圖放大後點任一處的「在全臺立體地景中飛到這裡」。

截圖：`docs/world/*.jpg`。

## 1. 做法：從「每個景點即時抓資料」改成「全臺預先切好的圖磚」

| 層 | 資料 | 來源與授權 | 載入方式 |
|---|---|---|---|
| 地形 | Terrarium PNG 高程圖磚（約 30 m 網格） | [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)（Mapzen；SRTM、GMTED2010、ETOPO1 等），免費、須標示 | 依鏡頭距離 z8–z13，z14 圖磚取 z13 的四分之一 |
| 道路、建物外框與樓高、水域、土地覆蓋、地名、山峰、車站 | OpenMapTiles 架構向量圖磚（MVT，最細 z14） | OpenStreetMap（ODbL）經 [OpenFreeMap](https://openfreemap.org/) 每週切片，免費、無金鑰、無流量上限；須標示「© OpenMapTiles © OpenStreetMap contributors」 | 每張地形圖磚配同層的向量圖磚畫地表貼圖；z14 另外長出立體建物、道路、樹 |

因為圖磚是別人已經切好、放在 CDN 上的，**本站不必存任何全臺資料**，GitHub Pages 的容量限制不受影響；第一次看某處約 0.05–0.2 秒一張（使用者瀏覽器實測），之後瀏覽器快取。

### 四分樹 LOD（`src/world/tiles.js`）

- 從涵蓋臺灣與離島的 z8 根圖磚開始，鏡頭離圖磚越近就切成四張子圖磚，直到 z14。門檻：距離 < 邊長 × 0.8（z13→z14 為 0.5），「遠近細緻度」參數可整體放大或縮小。
- 一般視角約 100–120 張圖磚，其中 z14（有立體建物）約 8–16 張，約鏡頭周圍 2–4 公里；拉到「全臺俯瞰」只剩 20 張根圖磚。
- 缺的圖磚先用已載入的父圖磚或子圖磚補，不留洞；祖先與子孫不同時顯示。相鄰不同層級的地形以 60 m 裙邊遮縫。
- 快取上限約 260 張，超過丟最久沒用的。

### 背景執行緒（`src/world/tile-worker.js`）

下載、解碼、生成全在 Web Worker（2–4 個），主執行緒只組 three.js 物件，所以拖曳時不會卡。每張圖磚產生：

1. **地形網格**：z14 為 128×128（約 17 m），其餘 64 或 48；海拔低於 0 壓到 −60 m，由海面平面覆蓋。
2. **地表貼圖**（OffscreenCanvas，z14 為 1024²）：高程色（平原農地→丘陵林→高山林→岩屑）＋西北光地形陰影，再畫土地覆蓋、土地使用、公園、水域、河道、機場、建物底、道路與鐵道。
3. **立體建物**（z14）：裁到圖磚邊界（跨圖磚的建物兩邊各畫一半，不重疊），底部貼最低地面、樓頂依中心點地面＋樓高；立面沿用現代街景的程序化街屋材質（窗格、店面、招牌帶、鐵窗、夜間窗光）。
4. **立體道路與鐵道**（z14）：依等級給路寬，每 6 m 取樣貼地（與地形網格三角形一致的高度）；橋依 `layer` 抬高、兩端 50 m 漸變接地、每 32 m 一根橋墩；隧道不畫。
5. **樹**：林地、公園、校園、墓地遮罩扣掉建物道路水域後撒點，每張最多 3,500 棵。
6. **地名**：城鎮（依層級篩選）、山峰（含海拔）、車站。

### 建物高度（`src/world/heights.js`）

OpenMapTiles 只留 `render_height`：OSM 有 `height` 或 `building:levels` 才是實際值，都沒有時預設 5 m。臺灣大多數建物沒標樓層，所以 **5 m 視為未知**，依面積與該圖磚的建物覆蓋率（市區／郊區／鄉間）推估樓層，用位置雜湊決定（同一棟每次一樣；「重擲推估高度」換種子）。依據表會標出近景有幾棟是推估。

## 2. 場景功能（共用面板）

- 鏡位：鳥瞰街區、斜俯近景、街口人眼（自動進入漫步）、城市遠望、全臺俯瞰。
- 時刻、天氣（晴、多雲、雨、霧）、焦距、漫步（貼地人眼高度，可走遍全臺）、拍照、分享網址、純畫面。
- 片場參數：地形起伏（1–3×，像參考工具的 hf）、推估樓高、路寬、遠近細緻度；開關：白模檢視、樹木、地名；動作：重擲推估高度、匯出 GLB（近景地形＋建物＋道路）。
- 分享網址記住：位置 `ll`、距離 `d`、方位 `hd`、俯角 `pt`、`t`、`w`、`mm`、`seed`、`hs`、`rs`、`ex`、`clay`、`trees`、`labels`、`walk`。

## 3. 測試

- `npm test` 加了 `tests/world-tiles.test.mjs`：座標換算、臺南車站圖磚編號、根圖磚涵蓋本島與金門馬祖澎湖蘭嶼、LOD 不重疊且完整覆蓋、Terrarium 解碼、樓高推估。
- `tests/world-e2e.mjs`（需先 `npm run build` 並 `npx vite preview --port 4173`）：無頭 Chromium 開五個視角＋漫步並截圖。**雲端測試環境連不到 OpenFreeMap**，向量圖磚改用 `tests/world-fixtures.mjs` 把 repo 內的臺南站區 OSM 資料轉成同架構的 MVT；地形用真的 AWS 圖磚。所以截圖裡只有臺南站區有建物與道路，其他地方是地形與高程色。
- 真實 OpenFreeMap 已在使用者電腦的瀏覽器從 github.io 網域實測：TileJSON 與圖磚皆可跨網域讀取，臺北 z14 一張約 765 KB、0.2 秒；圖層與欄位如上表。**上線後要在使用者瀏覽器再看一次真實畫面**（尤其臺北市區的建物量與幀率）。

## 4. 下一步

1. **自架全臺圖磚（選配）**：若想不依賴 OpenFreeMap，可在 GitHub Actions 下載 Geofabrik 臺灣 PBF，用 Planetiler（OpenMapTiles 架構）切成臺灣範圍的 PMTiles，放到可做 Range 請求的空間（Cloudflare R2 等；GitHub Pages 單站 1 GB 上限、不建議放大檔），`src/world/sources.js` 換網址即可。
2. **內政部 20 m DEM**：AWS 圖磚在臺灣約 30 m。可把內政部 DEM 轉成 Terrarium 圖磚自架，山區稜線會更銳利。
3. **樓高補強**：國土測繪中心三維建物或使用執照樓層資料，依座標比對後覆寫推估值。
4. **歷史層**：各景點的歷史年代、故事、地標模型疊在這層上；圓山「時代切換時建物長出來」的效果可以套用到任何景點，因為底下的建物量體是同一套資料（統一轉場由另一個工作處理）。
5. 已知限制：漫步無碰撞；建物只有量體與程序化立面；高架道路沒有匝道坡度；地球曲率未計入（全臺俯瞰時地平線是平的）；舊版 Safari（16.4 以前）不支援 Worker 內 OffscreenCanvas。
