# 首頁、景點切換選單與現代街景（2026-11-28）

使用者需求：首頁一打開就看到 3D 街景；全臺地圖仍是主要功能；景點會越來越多，需要好擴充、好切換的選單；參考兩個工具，找出「快速取得全臺現代街景」的做法，作為逐步加入歷史 3D 對照與故事的基礎，並參考片場搭建、參數化工具與美術提升方法。

截圖：`docs/home/*.jpg`。

## 1. 這次做了什麼

| 項目 | 內容 | 程式 |

## 2. 參考工具研究

### どこでもロケハン（tools.oyasumi-gamedev.com/rokehan）

給漫畫背景取景用的日本工具。重點：

- **資料**：建物、道路、河川全部來自 OpenStreetMap（ODbL）；預先整理好的國家資料（含臺灣）放在自己站上，沒有的地方即時查 Overpass API；高程日本用國土地理院、其他用 AWS Terrain Tiles；遠景用 OpenFreeMap（OpenMapTiles）；地名搜尋用 GeoNames／Nominatim 的本地清單；抓過的資料在瀏覽器快取 7 天。
- **高度**：有 OSM 高度就用，沒有就依用途與面積推估，並提供「重擲未知高度」。
- **操作**：地圖釘選、貼 Google Maps／OSM 連結或經緯度、國家城市清單、隨機座標；人眼 1.55 m、24 mm。
- **輸出**：PNG、SVG 線稿、GLB／FBX／OBJ。
- **技術**：three.js。

**我們採用的部分**：OSM＋Overpass 即時查詢＋瀏覽器快取（7 天）、預先下載（我們在 GitHub Actions 部署時烘焙候選景點）、依用途面積推估高度＋重擲、GLB 匯出、地圖點選任一處生成。**沒採用**：線稿渲染（風格不同）、高程（臺灣車站街區大多平坦，圓山等山景另有手工地形）、遠景圖磚。

### 街構 Streetform（formosa-streetscape-lab）

臺灣街屋生成器（萬華雨巷、府城日光、港都街角三個預設）。以使用者電腦瀏覽器讀取頁面與模組名稱得知：

- **自寫 WebGL 2 引擎**（非 three.js）：`engine/gpu.js、shaders.js、world.js、skylight.js`，模型 `models/shops.js、facades.js、props.js、curb-details.js`，世界在 Web Worker 生成。
- **參數**（`settings.js`）：街道寬度、建築樓層、街屋緊密度、單側建築數、路面濕度、騎樓深度、招牌密度、表面風化、曝光、面寬、進深、層高、陽台比例、屋頂水塔；光照情境（雨後暮光、午後晴光、港灣陰天、夜間燈火）；六種立面樣式（傳統磁磚、磨石子、磚造、綠釉磁磚、粉光水泥、老式商住公寓）；**種子**決定配置；每棟可單獨覆寫（`overrides`）。參數可存成 JSON 匯入匯出，並存在 localStorage。
- **美術**：每種材質一組真實貼圖（顏色＋表面），另有風化與路面磨損貼圖；著色器有陰影貼圖、立方體環境貼圖、天空可見度體積（類似大尺度 AO）、HDR 曝光＋ACES、bloom、顆粒、濕潤路面；招牌字用 Canvas 排成貼圖集（直式、橫式、副標）。
- **檢視模式**：寫實材質／白模／線框；街道視角／鳥瞰／聚焦建築。

**我們採用的部分**：種子化程序生成、片場參數列、白模檢視、臺灣街屋的辨識元素（騎樓店面、招牌帶、鐵窗、冷氣、頂樓水塔與加蓋）、濕潤路面、夜間窗光與招牌發光。**之後可以學**（見第 4 節）：真實 PBR 貼圖組、天空可見度 AO、招牌文字貼圖集、單棟覆寫、場景參數 JSON。

## 3. 現代街景的資料與授權

- **來源**：OpenStreetMap，ODbL。網站與匯出的 GLB 都要標示「© OpenStreetMap contributors」。這是開放授權、免費，**不需要使用者另做取捨**；與中研院圖層（CC BY-NC）不同，商業使用也可以。
- **取得順序**：`public/data/osm/<id>.json`（部署時 `npm run bake-osm` 烘焙，未提交到 git）→ 瀏覽器 Overpass 即時查詢（overpass-api.de、private.coffee、kumi.systems 三個端點輪流）→ Cache Storage 快取 7 天。
- **實測**（2026-11-28，使用者電腦的 Claude 內建瀏覽器）：Overpass 從瀏覽器可直接查詢（CORS 正常）。半徑 500 m：基隆驛 147 棟（約 38 秒，558 KB）、花蓮 1,104 棟、臺南州廳 2,175 棟；打狗、臺東兩處當下逾時。**即時查詢偶爾很慢或失敗**，所以正式站靠部署時預先下載，即時查詢當備援。
- **高度**：臺南站區測試資料 379 棟中只有 46 棟有 OSM 高度或樓層，其餘推估。依據表會標出比例，可信度 B／C。
- **Overpass 使用政策**：公共伺服器不保證可用，流量大時應自架或改用付費服務。本站流量小且有快取，目前不需要。

## 4. 從現代底稿到歷史對照：建議路線

1. **候選景點先有現代街景**（本次完成）：任何景點一加進資料庫就能看 3D，可以先拍照、找鏡位、寫故事。
2. **史料卡**（`docs/source-cards.md`）：同一座標整理舊照、古地圖（地圖頁可疊中研院圖層對位）、年代。
3. **地標換模型**：在現代街景上把主角建物換成 Blender 模型（臺南、臺中做法），其餘街廓先沿用 OSM。程式上就是把 `src/streetscape` 當底，另加一個「歷史年代」群組（拿掉現代高樓、換成街屋列），達到 `docs/art-direction.md` 驗收表後，`status` 改 `live`、填 `entry`。
4. **美術提升**（依投入順序）：
   - 真實貼圖組：磁磚、洗石子、紅磚、柏油各一組顏色＋粗糙度貼圖（Poly Haven CC0 可用），取代目前著色器的單色。
   - 天空可見度 AO：在街谷底部壓暗，量體感會明顯提升（Streetform 的 skylight 做法；three.js 可用 N8AO 或 GTAO）。
   - 招牌文字：用 Canvas 依 OSM `shop`、`name` 產生直式招牌貼圖集，夜間發光。
   - 單棟覆寫：點選建物改樓層、立面樣式（沿用首頁「街屋工坊」的資料結構）。
   - 場景參數 JSON：匯出／匯入整組片場設定，方便分享與版本管理。

## 5. 已知限制

- 立面窗格、招牌、鐵窗是即時著色器，**匯出的 GLB 只有幾何與顏色**，不含窗格。
- 漫步沒有碰撞（會穿牆）。
- 高架道路用 `bridge=yes`＋`layer` 推估高度，沒有匝道坡度。
- 地下化、隧道路段不畫。
- 小地圖的經度範圍從 119.2°E 起，金門（118.3°E）、馬祖在範圍外，目前會貼在邊緣。
- 夜景窗光偏白，招牌帶偏亮，之後可再調。
- 雲端測試環境連不到 Overpass，測試時用臺南站區的 OSM 資料模擬 Overpass 回應；真實 Overpass 已在使用者電腦的瀏覽器確認可用。
