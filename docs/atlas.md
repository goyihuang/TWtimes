# 全臺地圖首頁（MAP V2）說明

網址：`map.html`。2026-11-28 起網站根目錄 `./` 改為直接開 3D 街景（臺南驛前），地圖由頁首「全臺地圖」、景點列與首頁導覽卡進入；地圖頁首的「3D 街景」回到首頁。詳見 `docs/streetscape.md`。

候選地景只要有座標，預覽卡會出現「看現代街景 3D」（OSM 自動生成）；放大到 z14 以上點地圖任一處，可在該點生成現代 3D 街景。

## 三種瀏覽方式（共用同一組搜尋與篩選）

| 模式 | 內容 |
| --- | --- |
| 地圖 MAP | 全臺 22 縣市輪廓（離線可用）＋底圖；地景標記群聚，點擊看預覽卡，按「進入 3D 街景」。點縣市可直接篩選該縣市。 |
| 圖鑑 ATLAS | 縮圖卡片，列出名稱、縣市、年代、簡介、入口與地圖定位。 |
| 時間軸 TIME | 清領、日治、戰後、現代、未來規劃五欄，只列出地景**實際具備**的年代；點欄位標題即加入年代篩選，可一鍵在地圖疊上該年代古地圖。 |

- 搜尋：臺／台、全形半形、空白與標點都會正規化；比對名稱、舊名與別名（如「台中車站」「臺灣神社」「濱線」）、英文與羅馬拼音（`taichu`）、縣市、標籤、年份與簡介。空白分隔多個詞時須全部命中。打錯一兩字會以雙字元相似度做模糊比對。按 `/` 聚焦搜尋框。
- 多重標籤篩選：縣市、類型、主題、年代、建築現況、完成狀態。**同一類任一符合，不同類全部符合**（例：類型選「車站」＋縣市選「臺南市」→ 只剩臺南驛）。上方顯示目前條件，可逐一移除或清除全部。
- 狀態全部寫在網址 hash（模式、搜尋、篩選、選取地景、地圖中心與縮放、底圖、歷史圖層、透明度、滑桿位置），進入 3D 後按瀏覽器返回會回到原來的位置。
- 手機（≤820px）：清單改為底部資訊面板，拖把手展開；選取地景後面板收合，預覽卡浮在地圖上。
- 首頁只載入地景索引（`scene-registry.json` 約 20 KB）與縣市界（118 KB），Leaflet 延後載入；不預載任何 Three.js 或 GLB 模型。

## 地景資料庫 `public/data/scene-registry.json`

新增一處地景＝在 `scenes` 加一筆，地圖、圖鑑、時間軸會同步出現。

| 欄位 | 說明 |
| --- | --- |
| `id` | 唯一代號 |
| `name` / `nameEn` / `aliases` | 名稱、英文或羅馬拼音、別名與舊名（皆可搜尋） |
| `city` / `district` | 縣市用「臺」字（如臺南市），與縣市篩選一致 |
| `lat` / `lng` / `coordSource` | WGS84。**未查證填 null**：只出現在圖鑑與清單，不上地圖；`coordSource` 記錄座標出處 |
| `types` / `themes` / `buildingStatus` / `tags` | 類型、主題、建築現況、其他關鍵字；可選值在 `taxonomy` |
| `eras` | `[{ year, period }]`，`period` 必須是 `taxonomy.periods` 的 id。只列真正有建模的年代 |
| `thumbnail` | `public/` 下的相對路徑；目前在 `public/thumbs/`，640×400 JPEG，皆為本專案場景實際畫面 |
| `summary` / `sources` / `license` / `confidence` | 簡介、來源連結、授權、重建可信度（A 直接佐證／B 照片推估／C 示意） |
| `entry` | 已上線頁面的相對網址；`status` 不是 `live` 時必須為 null，不連到不存在的頁面 |
| `status` | `live` 已上線、`dev` 開發中、`planned` 候選地景 |
| `extra` | 選填，額外連結（如臺北車站五代影像對照） |

`npm test` 會檢查：必要欄位、id 唯一、上線地景有入口／座標／縮圖、未上線地景沒有入口、座標在臺灣範圍、年代分類存在、縮圖檔存在，以及搜尋與篩選的行為。

## 底圖與歷史圖層

| 圖層 | 來源 | 授權 |
| --- | --- | --- |
| 縣市輪廓（離線） | 內政部「直轄市、縣市界線」，經 taiwan-atlas（MIT）簡化；`scripts/build-counties.mjs` 可重製 | 政府資料開放授權條款 |
| 臺灣通用電子地圖（預設） | 內政部國土測繪中心 WMTS `EMAP` | 政府資料開放授權條款 |
| OpenStreetMap | tile.openstreetmap.org | ODbL，須標示；依 OSMF 圖磚使用政策，流量大時應改用自架或商用圖磚 |
| 歷史圖層 9 種 | 中央研究院「臺灣百年歷史地圖」WMTS（`https://gis.sinica.edu.tw/tileserver/wmts`，GoogleMapsCompatible） | **CC BY-NC**：須標示、限非商業。商業使用要向中研院智財技轉處另取授權（技轉案 20T-1100319） |

歷史圖層（`src/atlas/layers.js`）：1897 臺灣假製二十萬分一圖、1904 臺灣堡圖（明治版）、1921 臺灣堡圖（大正版）、1921 二萬五千分一地形圖、1924 五萬分一地形圖、1934 臺灣全圖、1944 美軍五萬分一地形圖、1945 美軍城市地圖、1956 土地利用及林型圖。圖層代號取自 GetCapabilities 原文；圖磚網址格式為 `file-exists.php?img={代號}-{副檔名}-{z}-{x}-{y}`。清領時期目前沒有已核對的全臺圖層。

疊圖用 Leaflet 一般 `<img>` 圖磚，不需要對方伺服器開 CORS。透明度與古今滑桿（左古右今，可直接拖曳畫面上的分隔線）都存在網址。底圖連不上時會提示並暫時改用離線縣市輪廓，不寫進網址。

## 程式

```
map.html                 頁面骨架
src/atlas/main.js        狀態、網址 hash、清單、預覽卡、圖鑑、時間軸、圖層控制
src/atlas/map.js         Leaflet、縣市輪廓、群聚標記、歷史圖層與古今滑桿（動態載入）
src/atlas/search.js      正規化、計分、篩選（純函式，可在 Node 測試）
src/atlas/layers.js      底圖與中研院圖層清單
src/atlas/atlas.css      版面（桌機側欄、手機底部面板）
tests/atlas-search.test.mjs
```

## 已知限制

1. 2026-11-28 已在使用者電腦的瀏覽器實測：臺灣通用電子地圖、OSM 與 9 個中研院圖層都能載入，用 Leaflet 疊在臺南、臺中、臺北站區時位置吻合（鐵道與站址對上）。依各圖層實際有內容的最高層級設定 `maxNativeZoom`（1897：15、1904：16、1921 堡圖：16、1921 地形圖：16、1924：15、1934：12、1944：16、1945：17、1956：15）。1921 堡圖在臺南市區 z13 以上沒有圖磚；1945 美軍城市地圖只涵蓋城市；1934 臺灣全圖是整張圖紙，含圖框。完整的 map.html 在實際 GPU 瀏覽器上要等上線後再看一次。
2. 新竹驛、嘉義驛、鹿港龍山寺座標尚未查證，暫不上地圖。
3. 候選地景尚無縮圖與模型，只是收錄清單，不代表已排程。
4. 主題「城門城牆」「未來規劃」目前沒有地景。
