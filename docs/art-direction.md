# 今昔街影｜統一美術與介面規範

更新：2026-11-28。適用於所有 3D 場景與地圖首頁。新場景上線前，依第 7 節的驗收表逐項檢查。

本規範以**臺南驛前**為標準（光影、史料面板、六鏡位、漫步都最完整），並沿用首頁既有的「歷史攝影編輯」風格：深綠、象牙白、暖金、鏽紅。

## 1. 介面：一個框架、一組控制項

所有場景都在首頁框架 `index.html?place=<key>` 裡開啟，不再各做一套全螢幕介面。

| 區塊 | 內容 | 程式 |
|---|---|---|
| 頁首 | 品牌、全臺地圖、街景探索、時空手記、我的攝影 | `index.html` |
| 城市列＋取景地點 | 臺中、彰化、臺北、臺南、高雄；下拉選地點 | `app.js`／`src/shared/platform-frame.js` |
| 主畫面 | 3D 畫布；左下年代與名稱；右側 ＋ − 重設；右下 環繞／步行；右上 說明、全螢幕 | 各引擎 |
| 側欄「街景索引」 | 同城地點卡片 → **共用場景面板** → 街區定位小地圖 | `src/shared/scene-panel.js` |
| 底列「時空切換」 | 年代按鈕（2–5 個）＋拍攝街景 | `src/shared/scene-panel.js` |

**共用場景面板**依序為：年代說明 → 鏡位 → 焦距 → 天氣 → 時刻 → 漫步／今昔並排／複製場景網址／純畫面 → 場景特有開關（如圓山的膠彩筆觸）→ 重建依據與可信度。引擎不支援的功能**直接隱藏**，不放沒有作用的按鈕。

### 互動共同規則

1. **切換年代時鏡頭不動**，才能做今昔比較。只有使用者選鏡位時才移動鏡頭。
2. **鏡位**：每個場景至少有「主鏡位（正面）」「鳥瞰」「人眼高度」三種，再加場景特有鏡位；目標六個（臺南、圓山已達成）。
3. **焦距**以 35 mm 等效 mm 表示（16–105），換算 `fov = 2·atan(12/mm)`。
4. **漫步**：人眼高 1.65–1.75 m；WASD／方向鍵；手機有畫面上的方向鍵或半邊拖曳。
5. **今昔並排**：同一鏡頭、同一時刻天氣，左舊右新，存入「我的攝影」。
6. **分享網址**：`?place=` 加上年代、鏡位、焦距、相機位置（`cam=px,py,pz,tx,ty,tz`）、漫步；舊網址參數一律保留相容（見 `docs/scene-contract.md`）。
7. **純畫面**：按鈕或 H 鍵，隱藏畫面上的所有疊加元件。
8. **鍵盤**：數字鍵／← → 切年代（圓山）、P 拍照、H 純畫面；焦點在輸入框時不攔截。

## 2. 色彩與字體（`src/shared/tokens.css`）

| 用途 | 變數 | 色碼 |
|---|---|---|
| 頁面底 | `--paper` | `#f5f2e9` 象牙白 |
| 面板底 | `--white` | `#fffdf5` |
| 主要文字、選中 | `--ink` | `#253d35` 深綠 |
| 浮層 | `--deep` | `#1d3129` |
| 次要文字 | `--muted` | `#58695c` |
| 分隔線 | `--rule` | `#c8cab9` |
| 品牌、強調 | `--rust` | `#a34730` 鏽紅 |
| 快門、選中年代（深底） | `--gold` | `#d1ab68` 暖金 |
| 可信度 A／B／C | `--conf-a/b/c` | `#3f6b4f`／`#a0742c`／`#8a8a80` |

- 標題：`--serif`（Georgia＋Noto Serif TC），字距 .04–.08em。內文：`--sans`（微軟正黑／蘋方）。英文副標：Georgia 10px、字距 2px、全大寫。
- 不用霓虹色、純黑、純白。夜景的燈光色用暖黃 `#ffd89a` 系。

## 3. 光影與調色

以臺南引擎為準（`src/tainan/main.js`＋共用後製 `src/yuanshan/post.js`）。

| 項目 | 規範 |
|---|---|
| 色調映射 | ACES Filmic；白天曝光 0.75–0.9，夜晚 0.6–0.9（依天光自動） |
| 太陽 | 依日期、時刻與經緯度計算方位與仰角；陰影用 PCFSoft，範圍只涵蓋主鏡位周邊 |
| 環境光 | Sky 天空經 PMREM 產生環境貼圖；不另放強烈補光 |
| 霧 | FogExp2：晴 0.0008、多雲 0.0016、雨 0.0045、霧 0.0062（臺南值；大尺度場景如圓山按比例調低） |
| 夜間 | 路燈要有實際光池（PointLight／SpotLight 或光池貼花），窗光用 emissive；bloom 只在夜間開，強度 ≤ 0.6 |
| 雨天 | 雨線＋地面濕潤（粗糙度降低、反射提高）＋天色變暗 |
| 年代調色 | 每個年代一組 `grade`：`sat con warm sepia lift vig grain paper teal`。日治以前 sepia 0.12–0.38、grain 0.03–0.05；戰後 teal 0.15；現代 sepia 0。調色只表現時代感，不能蓋掉模型缺陷 |
| 轉場 | 年代切換用淡入淡出（約 0.6–2.6 秒），鏡頭不動 |

**待統一**：首頁原有場景（臺中、彰化、臺北、高雄，`public/app.js`）已有簡化的時刻與天氣（由臺中 1935 版移植），但還沒有色調映射、年代調色與夜間光池，天空是固定照片。這是下一階段工作（見 `docs/scene-inventory.md` 第 4 節）。

## 4. 比例尺與座標

- 單位一律公尺；Y 軸向上。每個場景以主地標附近為原點，X/Z 依 OSM 投影（經緯度 → 公尺）。
- 地標模型：Blender 建模，原點在 OSM 外框外接矩形中心、長邊沿 X、正面朝向依 OSM 校正；網頁端不再縮放（`native: true`）。
- 尺寸要有依據：實測圖 > 官方文字 > 照片比例推估（標 B）> 示意（標 C）。照片推估要寫出參考尺寸（例：門廊拱高約 4.7 m）。
- 行人身高 1.6–1.75 m；樓層高：日治街屋 3.6–4 m、現代 3–3.3 m。用來做比例目視檢查。

## 5. 材質

- 主要地標用 PBR 材質（`MeshStandardMaterial`）＋程序貼圖或 CC0 實拍貼圖（Poly Haven）。材質名稱固定（例 `tn_tile`、`tn_trim`），方便依年代換外觀。
- 色票（基準，依照片微調）：紅磚 `#9b3b26–#a85844`、洗石子／灰泥 `#e5d6b9`、面磚淡褐 `#c9b08a`、日式瓦 `#4a4846`、銅綠 `#576d67`、木構 `#5a4330`、柏油 `#3b3d3c`、碎石路 `#b9ad97`。
- 不平貼假窗：窗戶要內縮、有窗框與窗台。
- 招牌不虛構歷史店名；只寫行業別或留白。

## 6. 史料、可信度與授權

每個年代都要有「重建依據與可信度」表：`[項目, A|B|C, 依據]`。

- **A**：照片或官方文字直接佐證。**B**：依照片比例推估。**C**：示意。
- 館藏照片授權未確認者，只作建模參考，不放上網站。公開影像要標授權（PDM、CC0、CC BY…）。
- 中研院歷史圖層為 CC BY-NC，不可商用。
- AI 生成圖只能標為「概念圖」，不能當史料。
