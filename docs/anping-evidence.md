## 1. 疊圖對位方法

1. 底圖：成大博物館〈熱蘭遮城與大員城下町〉今昔疊圖（卡 001），以 1600 px 寬檢視記錄座標。比例尺「300 ft」長 172 px，得每像素 **0.532 m**。
2. 第一次對位：把內城中心對到 OSM 安平古堡平臺（`b1` 無名多邊形）中心。為了讓市鎮街廓貼近效忠街，曾試過旋轉 12°。
3. 校正：現存「熱蘭遮城殘跡」（外堡南牆，OSM `m` way）是唯一留在原地的城牆。旋轉 12° 時南牆位置明顯對不上，所以改回**不旋轉**，整體平移東 3 m、北 8 m。校正後南牆位置差 < 3 m、方向差 2°。
4. 結果：內城中心在場景座標 (3, −8)。場景原點是 OSM 平臺中心 23.0015° N、120.16085° E，x 向東、z 向南、單位公尺。換算寫在 `src/anping/plan.js`。
5. 驗證：荷蘭市鎮 B、C 街廓之間的東西向大街大致落在今天的效忠街上，和「大員市鎮演變為安平街」的說法一致。延平街則斜穿 L、C、F 三個街廓。這表示疊圖本身的街道方向和今天的延平街不同，或者延平街並不是當年的大街。我們維持疊圖原樣，不硬把街廓對齊延平街。
